# KUBERA Offline AI — принцип работы

## Может ли агент работать без Интернета?

Да, если на отдельном сервере локально установлены:

1. модель (LLM),
2. embedding-модель,
3. локальная база знаний / RAG,
4. нужные программы и инструменты,
5. локальные копии данных.

После этого отключение Wi‑Fi/Internet не останавливает локальный агент. Он продолжает выполнять задачи, которые не требуют внешнего сервиса.

## Что продолжит работать без Интернета

- поиск по локальной базе знаний;
- работа с локальными документами;
- анализ текста и данных;
- локальный RAG;
- генерация текста;
- локальные скрипты и автоматизация;
- локальная Бхагавад-гита и другие книги;
- локальные файлы проекта KUBERA.

## Что НЕ будет работать без Интернета

- веб-поиск;
- GitHub API;
- внешние облачные API;
- отправка электронной почты через внешний сервис;
- онлайн-карты и актуальные данные;
- синхронизация с GitHub;
- любые сервисы, которым нужен внешний сервер.

## Важный принцип резервирования

GitHub должен быть одной из копий, но не единственной. Для действительно автономной системы нужно иметь минимум:

- рабочую копию на сервере;
- резервную копию на отдельном диске/NAS;
- удалённую копию GitHub или другого хранилища.

Если интернет исчезнет, сервер продолжит работать с локальной копией. Когда интернет вернётся, изменения можно синхронизировать с GitHub.

## Бхагавад-гита

Для KUBERA Learning желательно хранить локальную копию открытого текста/данных, а не только URL. Тогда исчезновение исходного сайта не уничтожит нашу рабочую копию.

https://github.com/gita/gita

Источник JSON стихов:
https://github.com/gita/gita/blob/main/data/verse.json

Источник переводов:
