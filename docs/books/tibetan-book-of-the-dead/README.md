# Тибетская книга мёртвых — Бардо Тхёдол

Основной текст для локальной библиотеки должен храниться в версии, права на которую позволяют воспроизведение в публичном репозитории. Перевод Evans-Wentz 1927 не копируется автоматически: его статус в Великобритании требует отдельной проверки.

Источник полного текста для чтения: Wikisource, *The Tibetan Book of the Dead*, Book 1 и Book 2.
