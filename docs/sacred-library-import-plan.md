# KUBERA Sacred Library — автоматическая сборка библиотеки

## Назначение

Этот документ фиксирует отдельную задачу: собрать физические тексты священных книг в локальную библиотеку KUBERA, чтобы локальный AI-агент мог читать их без интернета.

**Это отдельный модуль. Не смешивать его с Real Estate OS, другими AI-агентами или архитектурой проектов.**

## Принцип

Книги не помещаются целиком в system prompt.

System prompt только сообщает агенту, где находится библиотека и как с ней работать.

Сами тексты хранятся как реальные локальные файлы:

```text
KUBERA_SACRED_LIBRARY/
├── Bhagavad_Gita/
│   ├── Sanskrit/
│   ├── Russian/
│   └── English/
├── Shiva_Samhita/
├── Tibetan_Book_of_the_Dead/
├── Sai_Baba/
├── Mantras/
└── Prayers/
```

## Что нужно сделать позже

1. Для каждой книги определить конкретный текст/перевод, который можно законно сохранить и распространять.
2. Автоматически скачать разрешённые тексты из указанных источников.
3. Сохранить их в TXT/Markdown/JSON в соответствующих каталогах.
4. Создать manifest с названием, языком, источником, переводчиком и статусом лицензии/прав.
5. Проверить, что каждый файл действительно содержит полный текст, а не только ссылку.
6. Создать локальный индекс для поиска по книгам (RAG).
7. Подключить `KUBERA_SACRED_LIBRARY` к локальному агенту.
8. Сделать установочный скрипт, который на новом компьютере сможет восстановить библиотеку из облачной/GitHub-копии или из разрешённых источников.

## Важное правило

Не считать задачу выполненной только потому, что создана ссылка или README. Задача считается выполненной только после проверки наличия самого текста в репозитории/локальной библиотеке.

## Текущий статус

**План сохранён. Реальные полные тексты всей библиотеки пока не импортированы.**

## Первые источники для работы

- Bhagavad Gita: `https://github.com/gita/gita` — открытый структурированный набор данных.
- Shiva Samhita: `https://github.com/sanskrit/raw_etexts/blob/master/AgamAH/shaivam/shiva_samhita.md` — Sanskrit text.
- Bhagavad Gita Russian sources: `https://bhagavadgita.ru/` и `https://scriptures.ru/bh_gita.htm`.
- Tibetan Book of the Dead: использовать только текст/перевод с подходящими правами для предполагаемого распространения.

## Целевая архитектура

```text
Internet (только для первоначальной загрузки/обновления)
                    ↓
          KUBERA Sacred Library
                    ↓
              локальные файлы
                    ↓
               локальный RAG
                    ↓
             KUBERA Local Agent
                    ↓
              работа офлайн
```

После установки локальная библиотека должна оставаться доступной при полном отсутствии интернета.
