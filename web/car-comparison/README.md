# Kubera Car Choice — England to Spain

Интерактивная программа для сравнения подержанных автомобилей:

- редкая езда по Лондону;
- надёжность на длинном маршруте Англия → Испания;
- ориентировочные месячные расходы;
- доступность запчастей;
- безопасность;
- британский налог и проверка ULEZ;
- автоматический рейтинг с выбором приоритета.

## Запуск

Откройте `web/car-comparison/index.html` в браузере. Установка не нужна.

## Данные

В стартовую таблицу внесены восемь машин из предыдущего пользовательского сравнения. Диапазоны расходов рассчитаны для 600 миль в месяц и масштабируются при изменении пробега. Это инструмент предварительного выбора, а не замена проверки конкретного регистрационного номера, MOT history, страховой котировки и диагностики автомобиля.

## Главный предварительный результат

По исходному сравнению лучший общий вариант — **Honda HR-V 1.6 i-DTEC**. Программа позволяет менять приоритет между надёжностью, расходами и дальней поездкой.
